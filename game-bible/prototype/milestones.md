# Milestones — Suggested Order

1. **Interaction foundation:** character movement, prompts, usable interactables, puzzle state.
2. **Graybox chamber:** readable layout, clue placement, resonator manipulation.
3. **Puzzle feedback:** Web Audio tones, visual signals, failure/success states.
4. **Narrative payoff:** activation event, environmental reaction, ship reconstruction reveal.
5. **First external playtest:** observe confusion and delight; revise puzzle.
6. **Opening expansion:** cockpit, disaster, wreck, survivor, final transit departure.
7. **Recruitment-ready presentation (optional):** lighting, sound, gameplay footage, concise project pitch.

These are milestones, not calendar promises. Keep the first demo small enough to finish alone.

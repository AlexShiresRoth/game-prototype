# Core Gameplay — Proposed

## Loop

Explore a handcrafted site → observe environmental clues → interact with machinery/NPCs → solve a physical or signal-based puzzle → discover a frequency fragment or network function → return to the ship → discuss implications with crew → choose next accessible destination.

## Pillars

- Third-person traversal and interaction.
- Environmental problem solving; player reasoning over abstract button-matching.
- Dialogue and companion relationships.
- Ship as hub, with navigation through unlocked network routes.
- Discoverable lore grounded in places and people.

## Avoid in first prototype

Combat, large inventories, sophisticated companion AI, procedural galaxy, multiplayer, seamless interstellar flight, open-world simulation.
